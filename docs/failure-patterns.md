# Failure patterns to ban early

## Product failures

- Education-as-homework: quizzes with a game skin but no compelling fantasy.
- Broad toolboxes with no 3-minute first value.
- Content volume as a substitute for retention.
- Forced social dependency that blocks solo progress.
- Monetization prompts before the player understands value.
- Pay-to-win that damages the core social loop.
- Long onboarding before the first meaningful action.
- Features shipped without an event/KPI schema.
- High-touch support requirements in a low-price product.

## Growth failures

- Buying traffic before tutorial/core-loop retention is acceptable.
- Chasing visits instead of repeat play and profit.
- Misleading thumbnails/titles that increase clicks but reduce satisfaction.
- Copying a current hit so literally that differentiation, IP safety and update velocity disappear.
- Building many games before one acquisition/retention/monetization loop is understood.

## Automation failures

- One unconstrained agent with publish authority.
- No independent checker.
- No canary or rollback.
- Agents spending Robux/ad budget without a hard cap and explicit policy.
- Bots simulating real users, visits, clicks, rewards or reviews.
